- Create the full project folder structure (index.html, style.css, main.js, /data, /assets)
- Create `data/ldd.json` (DDL) — covering: CREATE TABLE, ALTER TABLE, DROP TABLE, ADD COLUMN, MODIFY COLUMN, RENAME, CONSTRAINTS (PK, FK, UNIQUE, NOT NULL, DEFAULT, CHECK)
- Create `data/lmd.json` (DML) — covering: INSERT INTO, UPDATE, DELETE, TRUNCATE, with examples
- Create `data/lid.json` (DQL/Queries) — covering: SELECT, WHERE, ORDER BY, GROUP BY, HAVING, JOIN (INNER, LEFT, RIGHT, FULL), subqueries, LIMIT, DISTINCT, aliases
- Each JSON file must include: title, description, sections → each section has: name, explanation, syntax, and multiple examples
